# Sustainable Material Cutting Optimization Using Deep Q-Networks — 代码

[English](README.md) | 简体中文

论文：Linxuan Chen, *Sustainable Material Cutting Optimization Using Deep Q-Networks: A Reinforcement Learning Approach for Resource Efficiency*, ITM Web of Conferences **73**, 01002 (2025), https://doi.org/10.1051/itmconf/20257301002 （PDF 见 `itmconf_iwadi2024_01002.pdf`）。

论文的原始代码已经丢失，本仓库是按论文描述重新实现的版本。论文正文没有写明的细节（图的构建、切割环境、奖励函数和部分超参数）在重写时重新确定，见下文“论文未写明、重写时确定的细节”，因此数值与论文中的图不完全一致。

## 与论文结果的对比

| 论文图 | 论文（从图上目测读数） | 重写版（seed 0） | 5 个随机种子 | 对比 |
|---|---|---|---|---|

| Fig. 4 GNN 测试 loss | 2.42 → 1.41 | 2.28 → 1.33 | 末值 1.37 ± 0.02 | 一致 |

| Fig. 6 总回报 | 397–415，无明显趋势 | −0.24–0.42，无明显趋势 | 前 50 回合和后 50 回合均值都是 0.13 | 定性一致，数值不可比（奖励定义不同） |

重写版在定性上得到了论文中的四张图。另外有三点需要注意：

1. **按论文的训练量（100 回合，ε 最低只到 0.61），DQN 还没有学到切割策略。** 训练结束后用贪心策略测试，材料利用率只有 13%（5 个种子 11 ± 2%），低于纯随机下刀的 31%。论文 Fig. 6 的回报曲线同样没有上升趋势，即在这个训练量下策略还谈不上收敛。
2. **训练更久也不行，除非改算法。** 把同一个 DQN 训练到 4 万回合，Q 值严重高估（最大 Q 均值涨到 78，而回报上限是 1），最终利用率 10%；而且它的 TD 损失也在训练 GNN，GNN 的纹理分类随之崩溃（测试准确率从 62% 掉到 31%）。加上“无效动作屏蔽 + Double DQN”这两个论文里没有的改动后，才学到 78%，高于随机可行下刀的 73%，仍低于 first-fit 启发式的 84%。
3. **在这个环境里，GNN 的嵌入没有帮助切割决策。** 同样的屏蔽 + Double DQN，状态里去掉 v_G 后利用率为 83%（最后 10 个 epoch 平均 80%，带 v_G 时是 79%）。这只是一个种子，各 epoch 之间有约 ±3 个百分点的波动，两者无法区分：没有证据表明 v_G 改善了决策。

以上三点都依赖于重写时设计的切割环境（论文没有给出环境定义）。

## 运行

```bash
uv venv --python 3.12 .venv
```

```bash
uv pip install --python .venv/bin/python -e .
```

数据集（彩色 200×200 版 KTH-TIPS，约 68 MB）：

```bash
mkdir -p data/kth_tips && curl -L -o data/kth_tips/kth_tips_col_200x200.tar https://www.csc.kth.se/cvap/databases/kth-tips/kth_tips_col_200x200.tar && tar -xf data/kth_tips/kth_tips_col_200x200.tar -C data/kth_tips
```

论文协议（Fig. 3–6，约 20 秒，CPU 即可）：

```bash
.venv/bin/python -m csp_gnn_dqn.reproduce
```

加上三个 4 万回合的扩展实验（再多约 15 分钟）：

```bash
.venv/bin/python -m csp_gnn_dqn.reproduce --extended
```

单元测试：

```bash
.venv/bin/python -m unittest discover -s tests
```

换随机种子：加 `--seed 1 --out-dir results/seed_1`。两个阶段也可以单独跑：`python -m csp_gnn_dqn.train_gnn`、`python -m csp_gnn_dqn.train_combined`（`--help` 查看全部超参）。相同种子下结果是确定性的。

## 论文中明确规定的部分

- 数据：KTH-TIPS，10 类 × 81 张 = 810 张；转灰度，裁成正方形后缩放到 128×128；用 LBP 直方图作输入特征。
- GNN：3 层 GCN（ReLU，式 (1) 的对称归一化带自环邻接矩阵）；Jumping Knowledge 把第 0–3 层表示拼接后接线性变换（式 (2)）；全局平均池化得到图向量 v_G；全连接层分类。
- DQN：状态 s = [v_G, f_C]；|A| = 100，动作为 (x, y, θ)，θ ∈ {0°, 90°}；MLP 隐藏层 128、64（ReLU）；回放池 10 000；batch 32；γ = 0.99；目标网络每 1000 步同步；平方 TD 误差（式 (6)）。
- 训练量：GNN 20 个 epoch；联合训练 20 个 epoch、100 个回合。

## 论文未写明、重写时确定的细节

以下细节论文正文没有写明，原始代码又已丢失，重写时的选择如下。

| 项目 | 重写时的选择 | 依据 |
|---|---|---|
| 图的节点和边 | 把图像切成 8×8 个 16×16 的 patch，每个 patch 一个节点（64 个），4 邻域连边 | 论文说“图像的高和宽表示为图节点”；直方图只能定义在区域上 |
| 节点特征 | patch 内的 uniform LBP（P=8, R=1）10 维直方图 | 论文说 LBP 直方图作输入特征。再拼上展平的灰度像素（`--features lbp+gray`）会明显变差，见下表 |
| 训练/测试划分 | 每类把第 3、7 两个尺度的图片作为测试集（630/180） | KTH-TIPS 每类只拍了一个实物（9 个尺度 × 3 种姿态 × 3 种光照），随机划分会把几乎一样的照片同时放进两个集合；按尺度留出测的是对未见过尺度的泛化 |
| 隐藏维度、优化器 | 64 维；Adam，lr 1e-3，batch 32 | 论文没写，取常用默认值，没有为贴合论文曲线调参 |
| ε 调度 | 初值 1.0，每回合 ×0.995 | 由 Fig. 6 的 ε 曲线反推，吻合 |
| 板材与订单 | 10×5 格的板（2:1），10×5×2 正好是 100 个动作；把整板随机“一刀切”分成若干矩形作为订单，逐件随机顺序给出，所以事后最优利用率是 100% | 论文没给环境 |
| 奖励 | 放置成功得“该件面积 / 板面积”，所以一回合的总回报就是利用率；放不下扣 0.02（一格）并丢弃该件。在剩余板面上哪里都放不下的零件直接跳过，不需要决策，也不扣分 | 论文没给奖励，所以 Fig. 6 的纵轴数值无法对齐 |
| f_C | 剩余面积、已切件数（除以板的 50 格）、当前件的宽高，再加 50 维占用图 | 前三项是论文列出的；不加占用图智能体看不到板上哪里空着 |
| Q 网络里的 v_G | 与 f_C 拼接前先做层归一化（不带可学习缩放）；GNN 本身仍按式 (2)，不做改动 | v_G 是无界的线性输出，GNN 训练过程中范数从约 0.4 涨到 6，而 f_C 在 [0, 1] 内 |
| 材料如何影响切割 | 灯芯绒、棉、亚麻三类有纹理方向的织物不允许旋转（θ=90° 无效） | 论文说决策依赖材料特性但没说怎么依赖；可用 `--no-grain-constraint` 关掉 |
| “联合 loss” | GNN 最小化 交叉熵 + λ·TD 损失（λ = 1，`--td-weight`），TD 损失经 v_G 反传进 GNN；Q 网络最小化 TD 损失。每个 epoch：GNN 过一遍训练集，每一步在一批图的交叉熵上加上一批回放样本的 TD 损失 → 跑 5 个回合，每步做一次 DQN 更新。报告的联合 loss 是 epoch 结束时的训练交叉熵 + λ × 该 epoch TD 损失的均值 | 论文描述的是 GNN 和 DQN 的联合 loss；Fig. 5 从 2.45 起步，说明是从头训练 |
| 策略评估 | 180 张测试图每张用两次（360 个回合），所有策略用同一批订单 | 让每种材料权重相同 |

## 结果

### 阶段一：GNN（Fig. 3、Fig. 4）

![Fig. 3](results/fig3_gnn_train_loss.png)
![Fig. 4](results/fig4_gnn_test_loss.png)

训练 loss 2.28 → 1.33，测试 loss 2.28 → 1.33，测试准确率 62%（5 个种子 59 ± 3%；论文没有报告准确率）。两条 loss 都用每个 epoch 结束时的模型计算，可以直接比较；epoch 内各 batch 的滑动平均另存在 `gnn_metrics.json` 的 `train_loss_running` 里。起点是 ln 10 ≈ 2.30，即 10 类均匀猜测；论文起点 2.6 高于这个值，应是初始化不同。20 个 epoch 时模型还远没有收敛。

节点特征的敏感性（种子 0 和 1，第 20 个 epoch）：

| 节点特征 | 训练 loss | 测试 loss | 测试准确率 |
|---|---|---|---|
| LBP 直方图（默认） | 1.33–1.37 | 1.32–1.37 | 62% |
| LBP 直方图 + 展平灰度像素 | 1.67–1.76 | 1.59–1.68 | 33–40% |
| 仅展平灰度像素 | 1.70–1.72 | 1.65–1.66 | 29–37% |

默认值是比较了这几种读法之后定的：它既最贴近论文的文字，也最接近论文的曲线。

### 阶段二：GNN + DQN（Fig. 5、Fig. 6）

![Fig. 5](results/fig5_combined_loss.png)
![Fig. 6](results/fig6_reward_epsilon.png)

- 联合 loss 2.29 → 1.33。TD 损失只有约 0.003，所以 λ = 1 时它对 GNN 几乎没有影响：交叉熵与阶段一最多相差 0.02。调大 `--td-weight` 可以让切割任务对 GNN 的影响更大。
- ε 曲线和论文重合。为避免双纵轴，回报和 ε 分成上下两栏画。
- 回报在 −0.24 到 0.42 之间波动，没有趋势，和论文 Fig. 6 一样。

训练结束后在测试集材料上评估：

| 策略 | 材料利用率 | 无效下刀比例 |
|---|---|---|
| GNN-DQN 贪心（100 回合训练后） | 13% | 86% |
| 随机下刀 | 31% | 49% |
| 随机可行下刀（只在放得下的位置里随机） | 73% | 0% |
| first-fit 启发式 | 84% | 0% |

### 扩展实验（论文之外）：训练 4 万回合

![扩展实验](results/extended_utilization.png)

| 设置 | 最终利用率 | 现象 |
|---|---|---|
| 论文原样的 DQN | 10% | 最大 Q 均值在第 4 个 epoch 涨到 78（回报上限为 1），TD 损失达到 389。因为 TD 损失也在训练 GNN，GNN 的分类也随之崩溃（训练交叉熵 2.25，测试准确率 31%）。贪心策略 94% 的下刀无效 |
| + 无效动作屏蔽 + Double DQN | 78% | Q 值稳定在 0.4 左右；利用率 76% → 78%，各 epoch 在 74–82% 之间（最后 10 个 epoch 平均 79%） |
| + 无效动作屏蔽 + Double DQN，去掉 v_G（消融） | 83% | 利用率 76% → 83%，各 epoch 在 72–83% 之间（最后 10 个 epoch 平均 80%） |

排查时我还单独试过几种变体（临时脚本，没有放进代码；状态只用 f_C、不含 v_G）：只加 Double DQN 时 Q 值不再发散，但利用率仍在 25% 以下；把无效下刀改成直接结束回合、或把惩罚加大到 0.2，利用率也都不超过 30%，即都没学会找可行位置。我的判断是 128-64 的 MLP 要从 50 维占用图里为 100 个动作各自学会“这里放不放得下”，样本效率很低。

## 局限

- 消融只跑了一个种子。带 v_G 和不带 v_G 的屏蔽 + Double DQN 最终相差在各 epoch 的波动范围之内，所以结论是看不出 GNN 嵌入有帮助，而不是它有害。在这个环境里材料只通过“能否旋转”影响切割，开了动作屏蔽后这一约束已经由屏蔽处理。
- 原始代码的图构建方式、环境和奖励已无从核对，所以 loss 的绝对值和回报的量纲只能与论文做定性对比。按尺度划分很可能比论文用的划分更严格。
- 表中论文一栏的数字是从论文图上目测读出来的，有 ±0.03 左右的误差。
